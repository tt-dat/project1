Week 1: Understand the mechanism of Linux Network Stack and capture raw bytes from network card


- Use Packet Socket and SOCK_RAW socktype to capture all Ethernet packet include header, Raw Socket only capture packet at a network layer and it decapsulates link-layer header. Packet socket also allow turn on Promiscuous mode of network driver

- Use if_nametoindex() to not to hardcode network interface

- Turn on Promiscuous mode using setsockopt() instead of ioctl to auto disable this option when socket is closed

- Program should run with sudo because it need CAP_NET_RAW capability at user namespace to govern it's network namespace

- With 802.11(Wifi) frame, driver will replace it header with a ethernet header with same information



Week 2: Protocol Dissector/Parser

- In general, compiler will make alignment for struct so that the access to the memory is efficent, __attribute__ ((__packed__)) in definition of struct ether_header tell compiler to preserve the "packed" structure, not to pad additional bit. It ensure that it will comply with the data transmited from network
- Every field in every struct with more than one byte must use ntohs(), ntohl() before use

- Each layer choose implementation of different protocols from field pushed by lower layer

- Each layer remove header and push it's payload(upper layer packet) and upper protocol

- Packet type is updated at each layer, and the last update will be chosen

- Use sprintf to write to temporary buffer to:
+ Decrease I/O operation(printf, fprintf...)
+ Manipulate the order of the output(what is printed first, next, last...)

- Use unsigned char instead of char for proper printing
